Fundamental physical constants API

A semantic gateway and API to the physical fundamental constants. Built for science, designed for discovery and machine actionability.

License: MIT

Fundamental physical constants knowledge base

A comprehensive digitization project that transforms CODATA fundamental physical constants into machine-actionable and legacy formats, enabling seamless integration with modern data science workflows, AI systems, and agent-based applications.

License: CC BY 4.0

SI Reference Point

The SI Reference Point is a digital representation of the SI Brochure, which defines the International System of Units (SI), the world’s internationally agreed system of units. By making core SI reference information available in machine-readable form, the SI Reference Point helps ensure that the SI can be used consistently in digital applications and data exchange. .

License: CC BY 3.0

Nature Commentary: Stop Squandering Data

The landmark publication 'Stop squandering data: make units of measurement machine-readable' outlining challenges and solutions for digital metrology.

License: Nature Editorial

CODATA-DRUM Draft Book

A technical companion and implementation guide outlining standard digital representation patterns and metadata standards to ensure datasets are AI-ready.

License: CC-BY-4.0

QUDT

A collection of open-source, semantic ontologies and data standards used to represent physical quantities, units of measure, and their mathematical dimensions in software and scientific data

License: CC-BY-4.0

Unified Code for Units of Measure (UCUM)

A code system intended to include all units of measures contemporarily used in international science, engineering, and medicine, providing unambiguous electronic representation and conversion.

License: UCUM License
